# Secrets

Clusterdeck retains Wave-derived secret storage for connection passwords and other values. On macOS, the encryption key is protected through the system credential store; secret values are not intended to be committed to JSON configuration.

Manage secrets in Settings → Secrets or with `wsh`:

```sh
wsh secret set DEPLOY_PASSWORD='replace-with-the-value'
wsh secret list
wsh secret get DEPLOY_PASSWORD
wsh secret delete DEPLOY_PASSWORD
```

A connection can refer to a stored password by setting `ssh:passwordsecretname` in `connections.json`. Secret names start with a letter and contain only letters, numbers, and underscores.

Anyone with access to your logged-in account and a running authorized Clusterdeck terminal may be able to invoke `wsh`. Do not print secrets into shared terminals or logs. See [Connections](./connections) and the [secret command reference](./wsh-reference#secrets).
