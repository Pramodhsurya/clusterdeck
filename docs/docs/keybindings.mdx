# Key bindings

Clusterdeck's documented shortcuts use macOS `Cmd` notation. Some actions vary by focused view; the application menu and `wsh --help` are the installed-version authorities.

## Global and layout

| Shortcut | Action |
|---|---|
| `Cmd+Shift+N` | New window |
| `Cmd+N` | Create the configured default block (a terminal by default) |
| `Cmd+T` | New tab |
| `Cmd+W` | Close the focused block; the pinned editor is protected |
| `Cmd+Shift+W` | Close the tab |
| `Cmd+1` … `Cmd+9` | Select a connection workspace from the rail |
| `Cmd+D` / `Cmd+Shift+D` | Split with a new block horizontally/vertically |
| `Ctrl+Shift+S`, then an arrow | Split above, below, left, or right |
| `Cmd+[` / `Cmd+]` | Previous/next tab |
| `Cmd+M` | Magnify or restore the focused block |
| `Cmd+I` | Refocus the current block |
| `Ctrl+Shift` | Show block numbers |
| `Ctrl+Shift+1` … `Ctrl+Shift+9` | Focus a numbered block |
| `Ctrl+Shift+Arrow` or `Ctrl+Shift+H/J/K/L` | Move focus among blocks |
| `Ctrl+Shift+X` | Replace an ordinary focused block with the launcher |
| `Ctrl+Shift+I` | Toggle terminal multi-input when multiple terminals exist |
| `F2` | Rename the current tab |
| `Cmd+F` | Search the focused supported view |
| `Cmd++` / `Cmd+-` / `Cmd+0` | Zoom the application in/out or reset zoom |
| `Cmd+Shift+R` | Refresh the UI |

The designated editor cannot be closed or replaced through protected layout shortcuts. `app:disablectrlshiftarrows` disables directional block navigation; `app:disablectrlshiftdisplay` hides the overlay.

## Explorer and file preview

| Shortcut | Action |
|---|---|
| Typed characters | Type-ahead selection in directory trees |
| `ArrowUp` / `ArrowDown` | Move selection |
| `PageUp` / `PageDown` | Move by a page where supported |
| `Enter` | Open the selected file or directory |
| `Backspace` or `Cmd+ArrowUp` | Go to the parent directory where supported |
| `Cmd+ArrowLeft` / `Cmd+ArrowRight` | Back/forward |
| `Cmd+O` | Open a path |
| `Cmd+E` | Toggle preview/edit for supported files |
| `Cmd+S` | Save in an editable preview or editor |
| `Cmd+R` | Revert in an editable preview |
| `Escape` | Close search/filter UI |

Explorer file activation routes supported files into Clusterdeck's designated editor at the top of the workspace.

## Web

| Shortcut | Action |
|---|---|
| `Cmd+L` | Focus the URL field |
| `Cmd+R` | Reload |
| `Cmd+ArrowLeft` / `Cmd+ArrowRight` | Back/forward |
| `Cmd+O` | Open a bookmark |
| `Escape` | Leave URL-field focus or close applicable UI |

`Cmd+F` uses the web view's find behavior when that view is focused.

## Terminal

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+C` / `Ctrl+Shift+V` | Copy/paste |
| `Cmd+K` | Clear terminal |
| `Cmd+F` | Find in terminal |
| `Shift+Home` / `Shift+End` | Scroll to top/bottom |
| `Shift+PageUp` / `Shift+PageDown` | Scroll by a page |
| `Cmd+Home` / `Cmd+End` | Scroll to top/bottom on macOS |
| `Cmd+ArrowLeft` / `Cmd+ArrowRight` | Move to beginning/end of line on macOS |
| `Shift+Enter` | Send the configured Shift+Enter newline sequence |

Terminal applications continue to receive ordinary control chords such as `Ctrl+C`. Bracketed paste, Option-as-Meta, and Shift+Enter behavior can be changed in [Configuration](./config).

## Process viewer and tab lists

The process viewer uses `Space` to pause/resume updates, `Cmd+F` to open filtering, and `Escape` to close it. Tab lists support arrow navigation, `Home`, `End`, `Enter`, and `Space` through their accessible tab controls.

Clusterdeck has no built-in AI shortcut. Keyboard navigation and accessible labels were expanded in 0.1.4; report unreachable controls in [GitHub issues](https://github.com/clusterdeck/app/issues).
