# Configuration

User configuration is stored under `~/.config/waveterm/`. This inherited compatibility directory remains in use; it is not current product branding. Open Settings for visual and JSON editors, or run:

```sh
wsh editconfig settings.json
```

The primary files are `settings.json`, `connections.json`, `widgets.json`, `backgrounds.json`, and `termthemes.json`. Values cascade from shipped defaults to user and narrower workspace/tab/block scopes. JSON keys use colon-separated names rather than nested objects.

## Application and connection settings

| Key | Default | Purpose |
|---|---:|---|
| `app:defaultnewblock` | `term` | `Cmd+N`/split creates a terminal; set `launcher` to open the launcher |
| `app:tabbar` | `top` | `top` or `left` tab bar |
| `app:confirmquit` | `true` | Confirm application quit |
| `app:focusfollowscursor` | `off` | `off`, `on`, or terminal-only `term` focus behavior |
| `app:disablectrlshiftarrows` | `false` | Disable Ctrl+Shift arrow and h/j/k/l block navigation |
| `app:disablectrlshiftdisplay` | `false` | Hide the block-number overlay |
| `conn:wshenabled` | `true` | Allow the inherited remote helper |
| `conn:askbeforewshinstall` | `true` | Ask before installing the helper |

Connection host, user, port, identity, shell, timeout, and password-secret settings belong in `connections.json`; see [Connections](./connections).

## Terminal and editor settings

| Key | Default | Purpose |
|---|---:|---|
| `term:durable` | `false` | Durable mode for new SSH terminals |
| `term:showsplitbuttons` | `false` | Show split buttons in terminal headers |
| `term:copyonselect` | `true` | Copy selected terminal text |
| `term:trimtrailingwhitespace` | `true` | Trim trailing whitespace when copying |
| `term:cursor` | `block` | `block`, `underline`, or `bar` cursor |
| `term:cursorblink` | `false` | Blink the terminal cursor |
| `term:bellsound` | `false` | Play a sound for BEL |
| `term:bellindicator` | `true` | Show a visual BEL indicator |
| `term:osc52` | `always` | `always` or focus-restricted OSC 52 clipboard access |
| `editor:minimapenabled` | `true` | Show the Monaco minimap |
| `editor:stickyscrollenabled` | unset | Enable Monaco sticky scroll |
| `editor:wordwrap` | unset | Enable editor word wrapping |
| `editor:fontsize` | unset | Override editor font size |
| `editor:inlinediff` | unset | Select inline rather than side-by-side diffs |

Additional supported terminal settings include font family/size, scrollback, theme, transparency, local shell path/options, WebGL, bracketed paste, Shift+Enter behavior, and macOS Option-as-Meta. Use the Settings schema and installed UI for accepted types and ranges.

## Preview, web, and layout settings

| Key | Default | Purpose |
|---|---:|---|
| `preview:defaultsort` | `name` | Sort directory previews by `name` or modification time |
| `preview:showhiddenfiles` | unset | Show hidden files in directory previews |
| `web:defaulturl` | Clusterdeck GitHub | Default web-widget URL |
| `web:defaultsearch` | Google query template | Search template containing `{query}` |
| `web:openlinksinternally` | unset | Choose internal versus external link opening |
| `window:tilegapsize` | `3` | Gap between tiled blocks in CSS pixels |
| `window:maxtabcachesize` | `10` | Maximum cached tabs |
| `window:magnifiedblockopacity` | `0.6` | Magnified-block backdrop opacity |
| `window:magnifiedblocksize` | `0.95` | Magnified block size fraction |
| `window:fullscreenonlaunch` | `false` | Start the foreground window fullscreen |
| `window:savelastwindow` | `true` | Reopen the last closed window |
| `window:confirmclose` | `true` | Confirm supported close operations |

Clusterdeck's supported release is macOS-first. Inherited Windows/Linux-only window and platform settings may remain in the schema for source compatibility but are not macOS product features.

## Privacy and updates

| Key | Default | Purpose |
|---|---:|---|
| `telemetry:enabled` | `false` | Explicit opt-in for event telemetry and diagnostic-ping eligibility |
| `autoupdate:enabled` | `false` | Inert compatibility key; Clusterdeck hard-disables the Wave updater |
| `autoupdate:installonquit` | `false` | Inert compatibility key |

Update Clusterdeck with `brew update && brew upgrade --cask clusterdeck` or a verified artifact from `clusterdeck/releases`. There is no configured Electron update feed. See [Privacy](./privacy) for the consent-transition requests and telemetry schemas.

## Examples and troubleshooting

```json
{
  "telemetry:enabled": false,
  "term:durable": true,
  "editor:minimapenabled": false,
  "window:tilegapsize": 5
}
```

- Validate JSON syntax if a file stops loading; the Settings JSON view reports parse errors.
- Use `wsh editconfig settings.json`, `connections.json`, `widgets.json`, or `backgrounds.json`; include the `.json` suffix.
- String settings support inherited `$ENV:NAME` and `$ENV:NAME:fallback` expansion.
- Do not place passwords or tokens directly in settings. Use [Secrets](./secrets).
- For widget and background formats, see [Custom Widgets](./customwidgets) and [Tab Backgrounds](./tab-backgrounds).
