# Getting started

Clusterdeck currently publishes a macOS Apple Silicon build. It is unsigned and unnotarized.

## Install with Homebrew

```sh
brew tap clusterdeck/tap
brew install --appdir=~/Applications --cask clusterdeck
```

Omit `--appdir=~/Applications` for a system-wide install. If Gatekeeper still blocks the app, right-click it and choose **Open**, or clear quarantine only for an artifact you obtained from the [Clusterdeck tap](https://github.com/clusterdeck/homebrew-tap):

```sh
xattr -dr com.apple.quarantine ~/Applications/Clusterdeck.app
```

Upgrade with:

```sh
brew update
brew upgrade --cask clusterdeck
```

For source builds, see the repository [build instructions](https://github.com/clusterdeck/app/blob/main/BUILD.md).

## First workspace

1. Add SSH hosts to `~/.ssh/config` and launch Clusterdeck.
2. Select a host in the connection rail. Clusterdeck creates or restores that connection's workspace.
3. Browse files in the left explorer. Selecting a file routes it to the editor at the top.
4. Open terminals from the widget rail. New terminals inherit the workspace connection.
5. If one terminal must target another host or run locally, use that terminal's connection control. This override does not change the explorer, editor, or sibling terminals.

The remote helper may be installed at `~/.waveterm/bin/wsh`. That path and `WAVETERM_*` environment variables are inherited compatibility identifiers. Learn more in [Connections](./connections) and [wsh](./wsh).

Telemetry is unchecked on first launch. Review [Privacy](./privacy) before opting in.
