# Clusterdeck release notes

## 0.1.4

- Removed built-in Wave AI and the short-lived coding-agent integration.
- Removed k9s/lazygit launcher code; the login-shell `htop` widget remains.
- Improved editor-at-top layout, workspace lifecycle, accessibility, config previews, PDF previews, and context menus.
- Made telemetry consent non-retroactive, removed dead legacy activity collection, and documented exact endpoint paths and restart-sensitive ping frequency.
- Hard-disabled the inherited Wave updater/feed; updates use Homebrew and `clusterdeck/releases`.
- Corrected package identity, documentation, legal notice, release history, and Pages deployment.

## 0.1.3

The immutable `v0.1.2..v0.1.3` range contains debounced autosave, pending-save flush, correct content when switching files, version/onboarding updates, and an incidental `.gitignore` update. It did not add editor test files.

## 0.1.2

The immutable `v0.1.1..v0.1.2` range contains Homebrew quarantine/tap-refresh documentation, remaining user-facing branding cleanup, and a login-shell/PATH fix for the then-present k9s, lazygit, and htop launchers.

## 0.1.1

Added the original app launchers, explorer file operations and reconnect fixes, remembered-password timing fixes, and workspace history.

## 0.1.0

Introduced connection-as-workspace behavior, the SFTP explorer, routed editor, per-connection layout persistence, and Clusterdeck identity on the Wave Terminal 0.14.5 foundation.

The repository's [RELEASES.md](https://github.com/clusterdeck/app/blob/main/RELEASES.md) is authoritative. Upstream Wave history belongs to the [upstream repository](https://github.com/wavetermdev/waveterm/releases), not to Clusterdeck's release sequence.
