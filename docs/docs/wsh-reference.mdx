# Common `wsh` command reference

This is a curated reference for commonly useful commands, not a substitute for the executable help. Run `wsh --help` for the complete public command list and `wsh COMMAND --help` for authoritative flags and arguments. Hidden implementation/debug commands are intentionally omitted.

## Files and graphical views

- `wsh view PATH` opens a file or directory preview; `-m` starts it magnified.
- `wsh edit PATH` opens an editable view and returns immediately.
- `wsh editor PATH` opens an editor and waits until it closes, making it suitable for `EDITOR="wsh editor"`.
- `wsh file` provides remote-aware `ls`, `cat`, `info`, `rm`, `write`, `append`, `cp`, and `mv` subcommands. Run `wsh file COMMAND --help` before destructive operations.

Examples:

```sh
wsh view README.md
wsh view -m .
wsh editor config.yaml
wsh file ls -l .
wsh file cp ./report.txt //server/~/report.txt
```

Paths use the current terminal connection unless a supported remote URI selects another route. Confirm the connection and destination before copying, moving, or deleting data.

## Blocks, terminals, and widgets

- `wsh run -- COMMAND [ARG...]` creates a command block. Useful flags include `--cwd`, `-m`, `-x` (close on success), and `-X` (close on any exit).
- `wsh term [DIRECTORY]` opens a terminal.
- `wsh launch WIDGET-ID` opens a configured widget; use `-m` to magnify it.
- `wsh deleteblock`, `wsh focusblock`, and `wsh blocks list` manage or inspect blocks.
- `wsh termscrollback` reads terminal scrollback; consult its help for ranges, last-command selection, and output files.

```sh
wsh run --cwd ./project -- npm test
wsh run -x -- ./build.sh
wsh launch cdapp@htop
wsh blocks list --view=term
```

## Metadata and variables

`getmeta`/`setmeta` operate on block or tab metadata. `getvar`/`setvar` manage persistent variables at supported scopes.

```sh
wsh getmeta
wsh getmeta -b tab "bg:*"
wsh setmeta -b tab title="Operations"
wsh setvar -b workspace ENVIRONMENT=staging
wsh getvar -b workspace ENVIRONMENT
```

Use `-b this`, `-b tab`, `-b workspace`, a block number, or an ID where the command's help permits it. Variables are not protected secrets.

## Configuration and backgrounds

- `wsh editconfig` opens `settings.json`.
- `wsh editconfig connections.json`, `widgets.json`, or `backgrounds.json` opens another supported configuration file.
- `wsh setconfig KEY=VALUE` changes a settings value.
- `wsh setbg` applies an ad hoc image or color to the current tab.

```sh
wsh editconfig settings.json
wsh editconfig widgets.json
wsh setconfig telemetry:enabled=false
wsh setbg --opacity 0.3 '#2457a6'
wsh setbg --center ~/Pictures/logo.png
wsh setbg --clear
```

`setbg` supports `--tile`, `--center`, `--size`, border-color flags, and `--print`; run its help for validation rules.

## Badges and notifications

`wsh badge [icon]` sets or clears a block/tab badge. The icon is an optional positional Font Awesome name. Flags include `--color`, `--priority`, `--beep`, `--pid`, `--clear`, and block targeting.

```sh
wsh badge check --color green
wsh badge bell --priority 20 --beep
wsh badge --clear
wsh notify --title "Build" "Build finished"
```

`wsh tabindicator` remains as a deprecated compatibility alias; use `badge` for new scripts.

## Secrets

Prefer `wsh secret ui` so values do not enter shell history. CLI forms are:

```sh
wsh secret set NAME=VALUE
wsh secret get NAME
wsh secret list
wsh secret delete NAME
```

Secret names start with a letter and contain only letters, numbers, and underscores. See [Secrets](./secrets) for storage and access cautions.

## Connections and workspaces

- `wsh conn status|connect|ensure|disconnect|disconnectall|reinstall` controls known connections.
- `wsh ssh` connects the current terminal through the inherited SSH implementation.
- `wsh workspace list` lists workspaces.
- `wsh wsl` remains a public inherited compatibility command, but Clusterdeck does not publish or claim a supported Windows build.

Remote GUI operations require Wave Shell Extensions at the compatibility path `~/.waveterm/bin/wsh` and SSH forwarding. See [Connections](./connections).

## Web, paths, and version

- `wsh web open URL` opens a web block and contacts that destination.
- `wsh wavepath config|data|log` prints inherited storage/log paths; flags can open or tail them.
- `wsh version --json` prints version details.

## Public command inventory

The registered non-hidden top-level commands in this build are:

`badge`, `blocks`, `conn`, `deleteblock`, `edit`, `editconfig`, `editor`, `file`, `focusblock`, `getmeta`, `getvar`, `launch`, `notify`, `run`, `secret`, `setbg`, `setconfig`, `setmeta`, `setvar`, `ssh`, `tabindicator`, `term`, `termscrollback`, `version`, `view`, `wavepath`, `web`, `workspace`, and `wsl`.

Clusterdeck has no built-in AI command. Use `wsh --help` as the source of truth if this curated page and an installed binary differ.
