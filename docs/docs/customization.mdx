# Customization

Clusterdeck retains Wave-derived themes, terminal palettes, tab backgrounds, and configurable widget rail behavior.

- Choose a terminal theme from a terminal's context menu or define one in `~/.config/waveterm/termthemes.json`.
- Choose a tab background from the tab context menu or define one in `~/.config/waveterm/backgrounds.json`.
- Change the right rail through `~/.config/waveterm/widgets.json`.
- Adjust layout gaps, fonts, cursor behavior, and editor minimap in `settings.json`.

The `waveterm` directory name is retained for compatibility. See [Configuration](./config), [Tab Backgrounds](./tab-backgrounds), and [Custom Widgets](./customwidgets) for focused examples.
