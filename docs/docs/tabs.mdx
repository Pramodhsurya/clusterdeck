# Tabs

Tabs contain Clusterdeck's tiled blocks within a connection workspace. Each workspace can keep multiple tabs and restores its layout when selected again.

## Tab layout system

Blocks form nested rows and columns. Drag a terminal block edge to place it beside another block, drag within a block to swap, and drag the divider to resize. The explorer remains in its left zone and the routed editor remains at the top; terminal layout is flexible around those product zones.

Close a focused block with `Cmd+W` or a tab with `Cmd+Shift+W`. Closing the designated explorer or editor exposes rail actions that can reopen them. The `window:tilegapsize` setting controls spacing.

New terminals inherit the workspace connection, but an individual terminal may override it. See [Workspaces](./workspaces), [Widgets](./widgets), and [Configuration](./config).
