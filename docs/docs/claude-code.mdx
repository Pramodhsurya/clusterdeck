# Claude Code hooks

Clusterdeck does not include a built-in AI assistant. You may run independently installed terminal tools such as Claude Code. This page documents only an optional terminal integration using the inherited `wsh badge` command.

Claude Code lifecycle hooks can set a badge on the current block or tab:

```sh
wsh badge bell --color '#f5a623' --beep
```

Clear it when the task completes:

```sh
wsh badge --clear
```

Configure these commands in Claude Code itself and review that product's hook and privacy behavior separately. Clusterdeck does not proxy the tool's model traffic or credentials. Badge icon names use Font Awesome names without the `fa-` prefix. See the [`wsh badge` reference](./wsh-reference#badges-and-notifications).
