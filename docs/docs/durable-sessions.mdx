# Durable SSH sessions

Durable sessions keep a remote shell process and terminal history available through temporary network loss, sleep, or an app restart. They apply to SSH terminals, not local terminals.

Enable `term:durable` globally or on a terminal. Clusterdeck uses the inherited Wave Shell Extensions job manager on the remote host and reconnects over SSH when possible. This requires the remote `wsh` helper and SSH forwarding; the helper is normally installed at the compatibility path `~/.waveterm/bin/wsh`.

Closing a connected durable terminal terminates its remote job. If it is closed while disconnected, cleanup occurs when the host reconnects. Remote processes and buffered terminal data remain subject to the remote account's permissions and storage.

See [Connections](./connections) for helper and forwarding requirements.
