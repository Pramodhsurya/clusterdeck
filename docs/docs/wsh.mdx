# `wsh` overview

`wsh` is the inherited command-line bridge between a terminal and Clusterdeck GUI blocks. It is available in local terminals and, when installed, in SSH sessions at the compatibility path `~/.waveterm/bin/wsh`.

Common examples:

```sh
wsh view README.md
wsh editor config.yaml
wsh web open https://example.com
wsh run -- npm test
wsh setconfig telemetry:enabled=false
wsh badge check --color green
wsh wavepath log
```

The app injects an authorization token and `WAVETERM_*` compatibility variables into managed terminal sessions. `wsh` is not a general standalone program and normally cannot control the app from an unrelated process.

Remote use depends on Wave Shell Extensions, SSH forwarding, and the helper installation described in [Connections](./connections). Clusterdeck has no built-in AI command. See the [curated common-command reference](./wsh-reference), and use `wsh --help` for the complete installed command list.
