# Clusterdeck

Clusterdeck is a macOS-first, open-source SSH workspace for moving among many hosts in one window. Selecting a connection in the left rail makes it the default context for the explorer, routed editor, and new terminals. Each connection keeps its own layout.

Clusterdeck provides:

- a connection rail populated from SSH configuration;
- a full-height SFTP explorer and open-editors list;
- a Monaco editor that autosaves and stays at the top of the workspace;
- terminal blocks, including an optional per-terminal connection override;
- inherited `wsh` commands and durable SSH sessions;
- configurable widgets, themes, and layouts.

Start with [Getting Started](./gettingstarted), then see [Connections](./connections), [Configuration](./config), and [Key Bindings](./keybindings).

## Privacy and support

Usage telemetry and its diagnostic ping are off by default. Read [Privacy](./privacy) before opting in. Report documentation or application issues in [clusterdeck/app](https://github.com/clusterdeck/app/issues).

Clusterdeck is an independent derivative of [Wave Terminal](https://github.com/wavetermdev/waveterm) by Command Line Inc. Compatibility names are retained where removing them would break existing configuration or remote helpers; they are not current product branding.
