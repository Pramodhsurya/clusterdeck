# Connection workspaces

In Clusterdeck, a saved SSH connection is the primary workspace context. The connection rail switches among them, and each connection remembers its tabs and layout.

New explorer, editor, and terminal blocks inherit the active workspace connection. A terminal may override its connection without changing the workspace default. Explorer file selections route into the designated editor rather than opening arbitrary floating editors.

Layouts persist automatically. The default layout has a full-height explorer, an editor at the top, and terminal space below; users can resize or split terminal blocks. Pending editor changes are flushed when switching or closing files, but you should still confirm remote writes before disconnecting.

Use [Key Bindings](./keybindings) for rail and tab navigation and [Tabs](./tabs) for layout controls.
