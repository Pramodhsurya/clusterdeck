# Tab backgrounds

Tab backgrounds are CSS-style presets stored in the compatibility path `~/.config/waveterm/backgrounds.json`. They can use colors, gradients, images, opacity, size, position, and CSS blend modes.

```json
{
  "bg@cluster-blue": {
    "display:name": "Cluster blue",
    "bg": "linear-gradient(135deg, #102040, #2457a6)",
    "bg:opacity": 0.9
  }
}
```

Apply a saved preset from the tab context menu. To apply an ad hoc color or image directly, use `wsh setbg`, for example:

```sh
wsh setbg --opacity 0.9 '#2457a6'
```

Only reference local image files you trust. A background URL or web resource can create network traffic separate from telemetry. The exact built-in definitions are in [backgrounds.json](https://github.com/clusterdeck/app/blob/main/pkg/wconfig/defaultconfig/backgrounds.json).
