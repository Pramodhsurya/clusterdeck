# Widgets and blocks

Clusterdeck lays out functional views as tiled blocks. Core views include terminals, the routed editor, explorer/file preview, web, system information, process viewer, and user-defined command widgets.

The explorer and editor have designated workspace zones. Opening a file from the explorer routes it to the editor at the top rather than creating an arbitrary editor block. Terminals fill the remaining workspace and can be split, resized, or moved.

The default `htop` command widget is retained and starts through a login shell. It requires `htop` to be installed on the selected connection. k9s, lazygit, and built-in AI are not default or supported product widgets in 0.1.4.

Use [Custom Widgets](./customwidgets) to configure the rail, [Tabs](./tabs) for tiling, or `wsh view PATH` and `wsh web open URL` for supported GUI views.
